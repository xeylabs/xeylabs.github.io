M1 Selesai: Sinyal Jaringan, Worker Solver, Origin SDK.

M1 is done. Four items closed in Mythic: JA4 TLS fingerprinting, ASN-based network scoring, a packaged Web Worker for proof-of-work, and origin verification helpers for Node.js and Python. Commits bc87ed9 through c7e4fc3.

JA4 fingerprinting (ADR-0010)

Fingerprint klien TLS membedakan browser asli dari klien HTTP ter-script. Server membaca X-Mythic-JA4 (di-set oleh proxy tepercaya yang men-terminasi TLS) dan menilai fingerprint terhadap pola browser yang dikenal. Nilai malformed atau hanya-prefix ditolak untuk menerima diskon known-browser — fingerprint yang diparrot tetap menjadi bypass terdokumentasi, jadi JA4 hanya advisory, dibatasi pada kontribusi risiko kecil.

ASN scoring (ADR-0010)

Autonomous System Numbers menambah sinyal level jaringan: ASN datacenter dan hosting mendapat skor lebih tinggi dari ISP residensial. Komponen ASNLookup baru me-resolve IP klien via database MaxMind GeoLite2-ASN (MYTHIC_ASN_DB). Path kosong berarti sinyal dinonaktifkan — valid. Path yang dikonfigurasi tapi gagal dibuka menolak startup: fail-closed pada miskonfigurasi, bukan degradasi diam-diam.

Web Worker untuk PoW solving

Grind proof-of-work berjalan di main thread, membekukan halaman pada difficulty tinggi. solveInWorker() mengemas solver sebagai Web Worker via Blob URL — tidak perlu file worker terpisah untuk di-host, bekerja dengan bundler apapun. Fallback ke solving main-thread saat Worker tidak tersedia (SSR, Node). MythicClient menggunakan worker secara default dan auto-start pengumpulan behavioral saat konstruksi.

Helper verifikasi origin

Token keputusan hanya bisa diverifikasi di Go. Origin yang menjalankan Node.js atau Python kini bisa memverifikasi token secara lokal dengan helper baru: parsePublicKey/verifyToken untuk Node, parse_public_key/verify_token untuk Python. Keduanya menegakkan tanda tangan Ed25519, expiry, dan encoding base64url kanonis. Terverifikasi lintas bahasa: token yang di-generate server Go terverifikasi di keduanya.

Verifikasi

go vet bersih, go test ./... -race hijau, SDK tsc --noEmit dan bun test hijau (15 test), Python pytest hijau (6 test). Setiap sinyal baru mendokumentasikan bypass-nya terlebih dahulu, sesuai aturan proyek. Yang tersisa: M2 (behavioral biometrics, menutup celah delay-attack) dan M5 (shared keystore untuk verifikasi multi-node).
