Project 001: XProtect ships public.

Today the lab's first project goes from repo to record: XProtect — adaptive bot mitigation, built as a captcha replacement for the era where captchas lose. AGPL-3.0, fully public, as of today.

The problem we picked

Captchas are dead, and the death is measurable. Solving farms sell a thousand answers for less than lunch. Vision models read image puzzles like text. Stealth browsers walk past the fingerprint checks that were supposed to catch them. Every static puzzle shares one failure mode: one solver, discovered once, kills it forever.

The thesis: never trust the client

XProtect assumes the browser is hostile by default. Every byte that arrives from a client is adversarial input — so the client SDK is a sensor, never a judge. Decisions happen server-side, in a deterministic risk engine that outputs named, auditable reasons. The pricing of abuse is layered: an adaptive proof-of-work costs a human about one second inside a web worker — and the same cost, per request, forever, for a bot farm. Risky traffic gets harder challenges. Critical actions can demand cryptographic proof. And the verdict travels as a short-lived, Ed25519-signed token your backend verifies locally — no callback needed.

The goal was never "unbreakable". The goal is to make abuse economically irrational.

We tried to break it first

Before launch, we ran the attacks ourselves. A ten-thousand-mutation storm over the token format caught a real acceptance bug: distinct strings decoding to the same signed bytes. A live chaos session found that one forged header defeated the per-IP rate limiter twenty times out of twenty. Both are fixed. Both are pinned by regression tests. A fuzzer now grinds the verification path in CI on every push. The bypass reports were the useful part — that's the culture we want this project to reward.

What it honestly can't do yet

v0 loses to a funded operator with a stealth browser and a native solver. We say so in the threat model, in writing. The answer is roadmap, not vibes: behavioral biometrics, cryptographic step-up, a learning engine. Public by default means the gaps are public too.

License

Everything — engine and SDK — is AGPL-3.0-or-later. Read it, clone it, break it. If you break it, tell us first, privately. Contributions are welcome under the CLA in the repo.

Project 001 is live. Project 002 is already queuing up.

— XEY LABS, SHIP DAY
