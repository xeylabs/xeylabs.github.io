M1 완료: 네트워크 시그널, Worker 솔버, 오리진 SDK.

M1 is done. Four items closed in Mythic: JA4 TLS fingerprinting, ASN-based network scoring, a packaged Web Worker for proof-of-work, and origin verification helpers for Node.js and Python. Commits bc87ed9 through c7e4fc3.

JA4 핑거프린팅 (ADR-0010)

TLS client fingerprints distinguish real browsers from scripted HTTP clients. The server reads X-Mythic-JA4 (set by a trusted proxy that terminates TLS) and scores the fingerprint against known-browser patterns. Malformed or prefix-only values are rejected from receiving the known-browser discount — a parroted fingerprint remains a documented bypass, so JA4 is advisory only, capped at a small risk contribution.

ASN 스코어링 (ADR-0010)

Autonomous System Numbers add a network-level signal: datacenter and hosting ASNs score higher than residential ISPs. A new ASNLookup component resolves client IPs via a MaxMind GeoLite2-ASN database (MYTHIC_ASN_DB). Empty path means the signal is disabled — valid. A configured path that fails to open refuses startup: fail-closed on misconfiguration, not silent degradation.

PoW 솔빙용 Web Worker

The proof-of-work grind ran on the main thread, freezing the page at high difficulty. solveInWorker() packages the solver as a Web Worker via Blob URL — no separate worker file to host, works with any bundler. It falls back to main-thread solving when Workers are unavailable (SSR, Node). MythicClient uses the worker by default and auto-starts behavioral collection on construction.

오리진 검증 헬퍼

Decision tokens were only verifiable in Go. Origins running Node.js or Python can now verify tokens locally with new helpers: parsePublicKey/verifyToken for Node, parse_public_key/verify_token for Python. Both enforce Ed25519 signatures, expiry, and canonical base64url encoding. Cross-language verified: a token generated by the Go server verifies in both.

검증

go vet clean, go test ./... -race green, SDK tsc --noEmit and bun test green (15 tests), Python pytest green (6 tests). Every new signal documents its bypass first, per the project's rule. What remains: M2 (behavioral biometrics, closing the delay-attack gap) and M5 (shared keystore for multi-node verification).
